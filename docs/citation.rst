Citation, licensing and source boundaries
=========================================

Use ``getCitation()`` or ``get_citation()`` for the short archived-release
citation. Retain the dataset DOI
`10.5281/zenodo.22131190 <https://doi.org/10.5281/zenodo.22131190>`_, the dataset
version, and the underlying supporting source for a specific observation.

The `canonical Observatory page
<https://lunarness.com/pages/fashion-statistics-observatory>`_ is the editorial
presentation of this existing release. Source URLs stored in individual
records support the underlying observations; the DOI identifies the archived
Lunarness synthesis. Neither replaces the other.

License scope
-------------

Both published package metadata records declare ``CC-BY-4.0``. The repository's
`LICENSE.md
<https://github.com/gokimedia/lunarness-fashion-data-observatory-2026/blob/main/LICENSE.md>`_
applies CC BY 4.0 to original Lunarness commentary, calculations, data structure
and documentation. This guide follows that existing documentation license.
It does not change the project's license or declare a new software license.

The grant does not transfer rights to third-party source pages, trademarks or
databases. Review the supporting publisher's terms before reusing its material.
The repository does not include proprietary source downloads or charts.

Contributions and corrections

<https://github.com/gokimedia/lunarness-fashion-data-observatory-2026/issues>`_
to report a reproducible software issue or a source correction. Include the
package version, record ID, expected behavior and a supporting source when
relevant. Never submit private customer measurements or credentials.
