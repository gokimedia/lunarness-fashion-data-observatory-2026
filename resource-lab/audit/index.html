What this audit checks

  1. Recompute each supplied sum or difference using decimal arithmetic.
  2. Keep point values, lower bounds and ranges visibly distinct.
  3. Withhold example comparisons when units, quantity definitions, time or scope differ.
  4. Identify missing caveats so a reader can return to the original provider.

Matching metadata establishes a starting point for reviewing comparability. Source coverage, sampling and measurement methods still require the provider's documentation.
