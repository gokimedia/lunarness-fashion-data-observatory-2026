# Data dictionary

| Field | Meaning |
|---|---|
| `metric_id` | Stable identifier for the observation or calculation. |
| `topic` | Broad analytical family such as media attention, ecommerce or circularity. |
| `geography` | Geographic coverage stated by the source. |
| `period` | Reference year or year-month. This is not necessarily the page publication date. |
| `entity` | Event, population, platform or material component being measured. |
| `value` | Reported or derived value. A trailing `+` marks a stated lower bound. |
| `unit` | Unit that must travel with the value. |
| `derivation` | Formula or label showing whether the value is reported or calculated. |
| `comparability_note` | Warning that prevents a value from being interpreted as a different metric. |
| `source_publisher` | Publisher or source pair credited for the observation. |
| `source_url` | Page supporting the observation. |

## Interpretation rules

- Media Impact Value (MIV) is not revenue, sales, profit, reach or audited advertising spend.
- The Fashion Week top-three totals cover only the three brands named by each source summary.
- Website visits are sessions/visits, not unique people or transactions.
- Eurostat online-purchase shares use people who used the internet in the preceding three months as the population base.
- EEA textile consumption is apparent consumption calculated from production and trade data.
- A range such as 2–8% must remain a range; do not replace it with a midpoint.
